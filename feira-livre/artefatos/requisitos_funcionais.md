# Requisitos Funcionais — Esboço

- RF-01: Página principal com informações da feira (datas, horário, local, regras).
- RF-02: Listar feirantes (nome, categoria, banca, contatos).
- RF-03: Listar produtos (descrição e categoria).
- RF-04: Buscar por produto/categoria com filtros.
- RF-05: Exibir agenda com próximas datas/eventos.
- RF-06: Exibir mapa das bancas com identificação dos feirantes.
- RF-07: Página de contato/sugestões.
- RF-08: Área admin mínima para aprovar/editar cadastros.
- RF-09: Destaques na home.
- RF-10: Exportar calendário (iCal) — opcional.
