# Feira Livre — Projeto Integrador

Este diretório organiza os artefatos do projeto integrador "Site da Feira Livre" para a disciplina de Requisitos e Modelagem.

Referência base: ver [Projeto_Integrador_Feira_Livre.md](../Projeto_Integrador_Feira_Livre.md) e o plano em [Plano_Semestral.md](../Plano_Semestral.md).

## Estrutura
- `artefatos/`: templates e documentos por entrega.
- `slides/`: apresentações (Marp) de kickoff e checkpoints.

## Política de Documentação
- Todos os artefatos deste projeto devem ser escritos em **Markdown (.md)**.
- Consulte o guia: [../Guia_Documentacao.md](../Guia_Documentacao.md).

## Entregas por Semana (resumo)
- 1–3: Visão + Stakeholders + Personas + Stories + Story Map
- 4–5: Priorização + Conflitos + Rastreabilidade
- 6: Classes + CRUD
- 7: Qualidade (Checklist)
- 8: Checkpoint Integrador
- 9–11: Casos de Uso + Diagramas Dinâmicos + BPMN
- 12: RNF com métricas
- 13: Protótipo + Testes de Aceitação
- 14–16: SRS + Apresentação + Ajustes
